# Agent Arsenal

A comprehensive collection of 2,800+ agentic capabilities, security assessment playbooks, and service automation skills for AI agents and LLMs.

## Overview

This repository provides structured skills with YAML frontmatter, execution workflows, automated playbooks, and tool schemas spanning:

- **Security & Vulnerability Assessment**: Reconnaissance, network scanning, cloud security, web penetration testing, and incident response.
- **Service Integrations & API Automations**: Cloud services, SaaS platforms, databases, and developer tooling.
- **Agentic Workflows**: Multi-step reasoning templates, verification patterns, and operational execution scripts.

## Structure

Each skill folder contains:
- `SKILL.md`: Metadata (name, description), operational guidelines, and usage instructions.
- Supporting scripts, reference materials, or automation schemas where applicable.

## Usage

Skills can be loaded into supported agentic frameworks, custom local LLM runners, or Ollama-based tooling by referencing the respective directory and instructions in `SKILL.md`.
